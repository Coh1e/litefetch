# 项目 AI 工作流

## 当前交付

2026-10-24（Asia/Shanghai）完成项目拆分和说明文档。此文件是后续部署设计，不表示已经安装、连接或运行 OpenPi、DeepSeek、rea 或沙箱。本轮未生成业务功能、任务运行记录、Pi 配置、凭据或桥接程序。

## 最小闭环

1. 人类提出目标，并确定范围、关键取舍与发布要求。
2. ChatGPT 阅读当前交接与产品范围，制定单项任务和可检查的验收标准。
3. 本地 CLI 桥接将任务交给该项目唯一的 OpenPi Agent；只有现有 CLI 不能满足交互需求时再考虑 RPC。
4. OpenPi 使用 DeepSeek 推理，调用项目本地工具完成分析或实现。逆向采用 https://github.com/morluto/rea ，保留样本哈希与证据出处。
5. OpenPi 返回差异、检查结果和执行报告；ChatGPT 审查证据，返工或接受。
6. 更新项目交接，进入下一任务。发布、远端推送及跨项目操作由人类决定。

## 任务与报告约定

每项任务包含：任务标识、目标、工作目录、输入依据、允许修改的路径、约束、验收标准和预期输出。任务应小到一次审查能看清其影响；不把整份路线图直接交给执行代理无限推进。

报告包含：完成/部分完成/阻塞状态、修改摘要和差异、实际运行的命令及退出结果、证据的项目相对路径、失败与未验证事项、下一步建议。密钥、访问令牌、密码和用户数据不进入报告。

## 项目隔离设计

后续配置放在本项目 `.pi/`；工具、依赖、缓存、临时数据和日志均放在本项目的被忽略目录。配置与任务记录独立；可信且只读的运行时可以复用，其他项目的目录不作为可写路径。

启用执行前必须验证实际的文件系统隔离能力，包括命令执行和子进程写入；仅检查路径字符串或编写 AGENTS.md 不构成沙箱。未验证隔离的执行器不得宣称已经隔离。

DeepSeek 凭据由人类通过后续选定的本地私密机制提供，排除 Git；不通过修改全局环境变量完成配置。安装器必须能将依赖、缓存和临时写入约束到项目内，否则不运行。

rea 的旧安装、历史配置与逆向样本在本机归档内，只作为参考。后续应在所属项目重新检查版本、调用入口和写入路径，不直接使用旧工作区的绝对路径配置。

## 仓库与历史证据

仓库保存源码、必要资源、依赖声明、许可证和可接手的说明。构建产物、工具安装、缓存、运行数据库、私有配置和大体积历史证据不入库。

`HANDOFF.md` 指向本机归档。上传 GitHub 后归档不会随仓库出现；仅凭仓库可以阅读源码与计划，继续旧样本逆向或历史端到端验收前，需要人类另行提供所需资料。Agent 不自动越过项目边界读取归档。
