# 按需展开的任务详情

2026-10-21：任务菜单/右键增加“任务详情…”，快捷键Alt+Enter，双击任务进入同一原生Qt对话框，不增加常驻工具栏按钮或新依赖。

只读文本显示任务标识、协议、状态、来源、目标位置、已接收/总字节数、优先级及完整最近原因。HTTP/FTP来源显示去掉URL密码；不会自动复制、导出或发送内容。文本可人工选择复制。详情按Task值复制成打开时快照，避免模态事件循环中任务容器改变导致悬空引用；后台继续运行，详情不自动刷新。

失败/暂停/中断任务提示可关闭后尝试继续，并说明从头重试可能清理暂存数据及BT重试会校验已有数据。不展示尚未实现的连接诊断。

## 结构化错误持久化

任务新增errorType，SQLite模式升级至5，增加error_type列并限制整数0..8；TransferError既有值显式固定为持久标识，不得重排。工作线程失败结果的类型与原因一起保存；完成、暂停或取消结果不当失败处理，继续及从头重试清空旧分类。旧数据库自动迁移，既有错误原因保留，分类默认None，不从文本猜测。模式高于5仍拒绝打开，避免降级写入。

详情对失败任务展示请求配置、目标位置、网络、服务器响应、TLS、磁盘、内部处理、资源变化等分类，并给出对应建议；None显示未分类。后端未细分的错误仍会较宽泛，例如ed2k普通异常映射网络。该修改不证明所有后端错误归类都准确，后续需按具体路径继续修正。

### BT 分类细化

根据项目实际使用的libtorrent 2.1.2头文件error_code.hpp及torrent_status.hpp注释，结合错误码与error_file组件判断；TLS上下文归TLS、已归属文件/partfile归磁盘、元数据加载归请求、严重异常组件归内部错误；明确的容量/权限/只读/I/O错误归磁盘、连接重置/拒绝/超时/不可达归网络、文件冲突归目标位置、文件被缩短归资源变化，未知异常不再默认磁盘。add_torrent错误亦通过相同分类，不再统一网络。没有新增Boost组件或其他库。

新增download-torrent-errors映射用例覆盖无错误、容量、连接、TLS组件、元数据、文件冲突/缩短、文件索引/partfile、未知错误。它验证类型映射，不证明真实TLS失败或实际磁盘耗尽的端到端行为；pause/checkpoint/优先级等辅助方法的错误仍有部分按原磁盘类别处理，尚未全面细分。

构建及BT相关3项测试通过，36.74秒（logs/downloader-tests-bt-errors.log），包含新增映射用例、现有本机BT/磁力链/恢复集成及文件选择界面测试。当前注册40项CTest；本次只运行受影响的3项，不称为40项完整回归已通过。

### ed2k 存储与目标错误

新增协议内部StorageError/DestinationError，不增加库：暂存创建、seek/read/write/flush、缓存复制/保存/提交及发布等明确I/O路径使用存储异常，已有目标及发布瞬间的目标冲突使用目标异常。Windows按MoveFileExW的ERROR_ALREADY_EXISTS/ERROR_FILE_EXISTS区分冲突，其余发布失败按存储处理；非Windows按file_exists区分。任务适配层分别映射Disk/Destination并保留操作原因，不再统一报告网络。

下载协调器先捕获这两种明确异常并关闭当前peer后向上传递，避免按普通来源失败吞掉、再寻找下个来源。损坏分片、协议不一致等普通来源异常维持原有换源行为；取消标志仍优先归取消。空间不足原有DiskSpaceError分类保持。旧缓存读取不成功时忽略该缓存并重新下载的策略未变，不宣称所有本地异常都完成细分。

构建及ed2k相关14项通过，4.59秒（logs/downloader-tests-ed2k-errors.log）。新增真实路径夹具以普通文件阻挡目标父目录，runEd2kTask返回Disk且零接收；已有不归任务所有的文件返回Destination并保留原内容。现有缓存恢复、文件发布、取消、坏来源回退和回环传输测试同组通过。未模拟实际磁盘写满或发布时权限变化，亦未用网络中途存储失败验证“不会尝试下一来源”的端到端时序。

#### 传输中途缓存失败的回环证据

后续在download-ed2k-download增加第7个真实TCP场景：先保存第一个9728000字节已校验分片，来源提供剩余12345字节；进度达到完整长度后，在第二分片的缓存文件位置创建目录，使QSaveFile无法创建输出。确认协调器抛出StorageError、当前来源观测到连接关闭、备用来源在250毫秒观察窗内无连接、目标未发布，原第一个分片仍逐字节准确。下载调用已异常返回，后续没有可继续换源的任务循环；负向观察窗不单独充当全部时序证明。

构建及该集成测试通过（1.49秒，logs/downloader-tests-ed2k-mid-storage.log）。这验证可控缓存路径冲突引发的真实存储错误，不等价于实际耗尽磁盘或权限撤销。场景经过协议协调器而非整个GUI/SQLite任务链；任务层Disk映射另由前述真实路径用例验证，不合并宣称完整GUI故障注入验收。
