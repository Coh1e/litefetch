# 克制、高效的原生界面

2026-10-21用户明确指定参考Everything的界面方向。采用其所指的紧凑列表与少装饰方向，不声称复刻某一版本像素布局，也不复制品牌资产。

主界面保留5个高频工具栏动作：添加、打开种子、取消、暂停、继续。文件/任务/选项/查看使用Qt原生菜单；浏览器接管、ed2k设置、两组限速及托盘入口移入菜单，既有功能和快捷键保留。Ctrl+N添加、Ctrl+O打开种子、Ctrl+P暂停、Ctrl+R继续；新增Ctrl+F定位名称/来源筛选、Esc在筛选框清空。

任务表隐藏行号与单元格网格、不换行，默认22逻辑像素行高，名称列占剩余宽度，类型/进度/速度/状态固定初始宽度。筛选仅隐藏不匹配行，不删除任务，不影响后台调度；按显示文件名和原始来源不区分大小写匹配。没有加自绘控件、皮肤库、卡片、插画、渐变或装饰色。普通编辑/选中焦点沿用Qt原生样式。列排序已实现，进度与速度按数值排序，刷新时按任务标识保持选择，详见downloader-task-sorting.md；列配置、筛选状态保存等尚未实现。

后续界面统一遵循以下约束：

- 主窗口以任务列表为中心，状态栏提供汇总，详细连接、来源、错误及协议信息按需展开。
- 常用操作支持快捷键和右键菜单；低频设置进入菜单或对话框，避免持续扩充工具栏。
- 使用系统字体、原生控件和清晰的焦点/选中状态；紧凑行高按逻辑像素随DPI缩放，避免牺牲可读性。
- 不加入首页推荐、资源信息流、大面积卡片、装饰动画或单独的皮肤依赖。
- 大量任务时优先保证滚动、筛选与操作响应；大列表性能需要单独测量，不能由当前小规模测试推断。
