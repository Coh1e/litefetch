# ed2k 校验与分块报文

2026-10-20。新增ed2k_hash.h/.cpp、ed2k_blocks.h/.cpp，仍仅依赖现有QtCore，无新增Boost模块、wx或后台进程。

FileHasher用Qt已有MD4实现流式计算，保持常量内存，不缓存整文件或所有分块hash。part为9728000字节；不足一part直接MD4；多part聚合各part MD4，恰好整part结尾时额外计入MD4空内容。该规则与固定aMule3.1.0 KnownFile.cpp:483后的边界表核对。result可重复读取，完成后拒绝继续输入；Qt不提供MD4时明确失败，不替换成其他算法。

分块请求按Client2Client/TCP.h与DownloadClient.cpp核对：32位使用e3/47，64位使用c5/a3；三个start之后才是三个exclusive end，缺少的请求位补零。单块最多184320字节，不越过9.728MB part，不接受重叠/空/越界请求。64位偏移必须由调用方明确表示已协商支持，当前基础Hello并未自动宣告此能力。

未压缩数据块解析支持e3/46与c5/a2，先检查16字节文件身份、偏移宽度、长度与实际正文一致性，然后要求完全包含于一个未完成请求范围内。只负责解码与范围核对；尚未跟踪已接收区间，因此重复数据/乱序落盘去重必须由接收状态机完成，不能把重复解析当作新进度。压缩块不由本解析器接收。
