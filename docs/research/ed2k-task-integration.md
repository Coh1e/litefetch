# ed2k 统一任务队列接入

2026-10-20，新增 `downloader/src/ed2k_task.*`，TaskManager 调用现有同进程 ed2k 下载协调器。Qt 为唯一 UI 技术，无新库、wxWidgets、aria2 或下载后端进程。

TaskManager 接受显式 Ed2kRuntimeOptions（服务器地址/端口、用户 hash、昵称、监听端口及操作超时），配置有效时可添加现阶段支持的 ed2k 文件任务。重新解析 source 得到规范身份和大小，拒绝零字节和超过 UINT32_MAX 的文件。未配置服务器时明确拒绝添加。

任务使用原有 SQLite tasks 表、并发上限、优先级与工作线程，不增加第二套任务表。source 已包含 ed2k 身份和大小，数据库重载会重新解析。缓存根目录固定在数据库同级 ed2k-cache；每个任务使用 taskId 的 SHA256 作为子目录名，避免数据库 ID 被当成相对路径。相同数据库目录和任务 ID 可继续定位旧缓存。

下载进度回送原有 TransferProgress/changed 信号。暂停和运行中停止通过原有原子取消标志接到协调器，在有界网络操作之间响应；保留完整校验缓存。SQLite 暂停状态重载后仍暂停，继续会恢复缓存。取消同样保留缓存并说明；从头重试仅清理本任务精确缓存文件；移除任务记录清理该任务缓存而保留最终文件。恢复/清理缓存受 PartCache 锁保护。
