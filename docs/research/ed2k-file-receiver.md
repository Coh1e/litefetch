# ed2k 进程内接收落盘（2026-10-20）

产品约束：保留 libtorrent，Boost 按已验证清单控制；不采用 aria2、不引入 wxWidgets、不启动独立 ed2k 后端进程。

`downloader/src/ed2k_storage.*` 使用既有 Qt Core 和 C++ 标准库，无新增依赖。工作线程持有接收器，在目标目录创建随机临时文件。每块重新检查文件身份、长度、文件范围、180 KiB 上限和 part 边界；网络层仍负责限定 outstanding 请求范围。

接收区间合并，重复及重叠数据只有新增字节计入进度，重叠处逐字节比较，冲突拒绝写入。区间数量上限 65536，防止任意碎片增长。写入失败使接收器失效；完整文件重新从磁盘流式计算 ed2k 哈希，匹配后才发布。哈希失败不发布。

Windows 发布使用同目录 MoveFileExW 重命名，仅设置 MOVEFILE_WRITE_THROUGH，不允许覆盖目标或跨盘复制，避免 QFile::rename 的复制回退暴露不完整最终文件，也不再依赖硬链接支持。发布前先销毁 QTemporaryFile 以释放其可能保留的底层句柄；重命名失败后接收器关闭并尝试删除临时文件。尚未发布的普通会话仍由 QTemporaryFile 析构清理。非 Windows 暂保留硬链接方案。实际验证使用当前工作盘，尚未在 FAT/exFAT 实盘验证；WRITE_THROUGH 不代表已证明断电恢复。

当前只支持会话内接收，尚未实现区间持久化、崩溃恢复、分 part 校验后的坏块重取、排队/上传、服务器找源、Kad、协议压缩和 UI 接入。不能据此宣称完整 ed2k 下载已可用。

验证：构建通过；`logs/ed2k-storage-tests.log` 的 5/5 ed2k 测试通过。新增测试覆盖乱序、重复、跨区间重叠、冲突、未完成拒绝发布、错误哈希、已有目标及目标创建竞争、非法块和临时文件清理。未进行公网 eMule/aMule 互操作验证。

Windows 原生发布回归：第一次全量测试为 14/15，定位到 QTemporaryFile::close 保留原生句柄导致重命名失败。改为释放文件对象后，logs/ed2k-native-publish-tests.log 的 5/5 ed2k 测试通过（1.45 秒），包括新增中文目标名、空文件和重复发布用例；其他 14 项在此前全量运行中通过，尚未在修复后重跑全量。
