## 票面写明"未验证"的部分（本表不覆盖）

| 票 | 未验证内容 | 原因 |
|---|---|---|
| #16 | 元数据流量桶接入真实 BT 元数据下载 | 本环境无法获取 libtorrent 源码级钩子 |
| #17 | 真实 BT 网络与私有 tracker | 无真实种源 |
| #18 | 只读卷（实验用拒绝写入目录） | 无法制造只读卷；表现一致但介质不同 |
| #23 | 点击下载 → 暂停 → 交接 → 提交 | 见 `docs/research/browser-handoff-real-chrome.md` |
| #25 | 完成后打开文件夹 | 会拉起资源管理器，进程内无法断言 |
| #26 | 高对比目视、纯键盘走查、逐状态画板 | 需要人或真实主题；Figma 页面 02+ 读不到 |
| #28 | 干净 Windows 全范围验收 | 本机不是干净环境，也无第二台机器 |
