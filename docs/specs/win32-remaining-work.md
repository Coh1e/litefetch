## 已定取舍（不要重新讨论）

- **托盘与通知**：#29 故事 32 在范围内；关闭窗口默认退出，不隐式后台运行；通知只对“用户可见的完成”发一次，不做静默补发。验收必须在一台有通知区的真实桌面上做。
- **凭据**：未勾选“记住密码”时只在内存；勾选后按主机写入 DPAPI；跨账户不能解密时重新询问，不伪造可移植性。日志、复制、导出不得出现明文。
- **UI**：原生控件度量优先于 Figma 静态像素；新建对话框保持现状（比设计宽 +24.7%，不裁字段）；窗口标题统一为 `LiteFetch`；非 BT 属性页按“常规/传输/连接”分页；上传段显示真实字节，未知才显示“—”；对话框字体跟随系统消息字体。
- **结构**：命令表是命令的唯一枚举；`list_layout.*` 删除，列宽只保留 `columns.cpp` 一份；一次重构一个提交。
- **文档**：不为收尾再新增状态文档；`docs/research` 只加索引，不改写历史结论。
